# ☁️ SC500-LAB

> A hands-on Cloud & AI Security Engineer Bootcamp built from the ground up.

---

## 🎯 Objective

This repository documents my journey through a 10-week Cloud & AI Security Engineer Bootcamp.

Rather than only studying theory, every concept is implemented in a real Azure lab using industry-standard tools and best practices.

The goal is to develop the practical skills expected of a Cloud Security Engineer working with Microsoft Azure.

---

# 📖 Learning Philosophy

Every topic in this repository follows the same methodology:

1. Learn the concept
2. Build it
3. Secure it
4. Break it safely
5. Investigate it
6. Automate it

The objective is not only to pass certification exams, but to develop the practical skills required of a Cloud Security Engineer.
